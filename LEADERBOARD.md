- **Results**: cases where Claude did everything the task asked. Claude without the skill has a fair chance here.
- **Follows the skill**: cases where Claude kept every rule the skill states (each rule quotes the skill). Without the skill Claude was never told these rules, so this shows the skill was read and obeyed, not that the work got better.
- **Tokens** and **time** are for the whole set of cases, median over verifiers. Verifiers run on their own Claude subscription, so a run costs allowance, not money; tokens include Claude Code's own prompt read from cache.
- A result counts when at least 3 people other than the author agree within 1 case. **The model is reported by each verifier and not checked.**
