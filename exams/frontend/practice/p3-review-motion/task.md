# Code review

`app.css` holds the motion of a small web app (account menu, toasts, dialogs, a side drawer, a command palette opened with Cmd/Ctrl+K).

Write your findings to `review.md` in this folder: one problem per line, as `file:line — what is wrong — how to fix it`.
List only real problems; do not list things that are fine. Do not change the source files.
