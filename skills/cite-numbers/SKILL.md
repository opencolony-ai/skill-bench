# Numbers with sources

- Every number you write is followed immediately by its source in square brackets:
  `[<file>:L<line>]`, the line of that input file where the number appears. Copy the number
  exactly as it is written there (keep its thousands separators).
- A number you computed is followed by `[calc: <expression>]` using only numbers you cite
  elsewhere in the summary, e.g. `12.5% [calc: 450 / 3,600]`. Percentages: one decimal.
- Quarter names (Q1), years and list markers are not numbers.
